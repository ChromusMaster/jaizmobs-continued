# Jaiz Mobs Continued

Jaiz Mobs Continued is a Fabric mod with a bunch of strange creatures spread around the Minecraft world. Some are friendly, some are not, and a few are just a bit weird.

This source refresh targets Minecraft Java 26.2. The old mob ideas, textures, sounds, drops and general behavior are still here, but the project structure and code were brought over to the current Fabric setup.

## Current target

- Minecraft Java 26.2
- Fabric Loader 0.19.3
- Fabric API 0.157.0+26.2
- Fabric Loom 1.17.19
- Java 25

## What the mod has

There are mobs for several biomes and dimensions, including totem spirits, trufflers, aquatic creatures, golems and some End and Nether creatures. The mod also adds a small set of materials, equipment, food, spawn eggs and sulfur ore generation.

## Project notes

Client rendering and animation code now lives in its own source set. Repeated attack and glowing-eye logic was also shared where it made sense, and the data files use the newer Minecraft folders and formats.

This is still a continued version of an older project. The gameplay was kept close to what it already did, so there may be odd balance choices here and there. That is kind of part of it.

## Credits

The original mod, creature ideas and assets were made by Jaiz. This continued project keeps that work going on newer Minecraft versions.
