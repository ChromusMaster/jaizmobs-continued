# JaizMod

JaizMod brings the content of **JaizMod** and **Jaiz Mobs** together in one Fabric mod for Minecraft Java 26.2. This is an authorized community continuation maintained by ChromusMaster; it is not a replacement for Jaiz's original projects.

## Highlights

- 32 creatures, ranging from ambient wildlife to dangerous encounters
- structures, equipment, trims, food, tea, plants and other Vanilla+ additions
- ten wood families, with boats, chest boats and the usual building pieces
- a dedicated advancement tab built around the mod's own content
- seven new Overworld trees and a harvestable guarana bush in version 2.3.9

Existing worlds remain usable. New trees and guarana generate only in chunks explored after installing the update.

## Requirements

- Minecraft Java 26.2
- Java 25
- Fabric Loader 0.19.3 or newer
- Fabric API 0.158.0+26.2
- TerraBlender 26.2-26.2.0.0.2

Terraform Wood API 17.0.1 is bundled with the mod.
